# Групповая переоценка лифтов EPSS

Streamlit-приложение переносит часть стоимости монтажа из RUB в цену лифта в CNY.
Логика перенесена с листа `Групповая переоценка` исходного Excel-калькулятора.

## Что умеет MVP

- загружает исходный Excel-калькулятор или позволяет заполнить таблицу вручную;
- загружает файл расценки с листом `Стоимость` и берет из него цены лифтов;
- рассчитывает перенос по методу `Процент` или `Фиксированная сумма`;
- ограничивает фиксированный перенос стоимостью монтажа за 1 остановку с наценкой;
- показывает результирующую таблицу и сводные показатели;
- экспортирует копию исходного файла расценки с обновленными ценами на листе `Стоимость`.

## Запуск

```powershell
cd lift_repricing_app
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
streamlit run app.py
```

## Импорт файла расценки

В основном сценарии загрузите файл расценки проекта. Приложение ищет лист `Стоимость`
и берет данные из колонок:

- `Продукт` -> лифт;
- `Кол-во этажей` -> количество остановок;
- `Общая стоимость для клиента` -> цена лифта для клиента, CNY;
- `Стоимость монтажа за этаж` -> монтаж за 1 остановку без наценки, RUB.

Если в файле есть `Курс рубля у Юаню` и `Наценка МОНТАЖ`, они подтягиваются
в общие параметры проекта. После импорта параметры можно изменить вручную.

## Экспорт

Кнопка `Скачать обновленную расценку` возвращает исходный Excel-файл расценки
с сохраненной структурой листов и форматирования. Файл патчится точечно, без
пересборки книги. На листе `Стоимость` обновляются:

- `Общая стоимость для клиента` -> формула `старая цена + перенос в CNY`;
- `Стоимость монтажа за этаж` -> формула новой базовой ставки монтажа после переноса.

Старые формулы и связанные колонки остаются формулами. Если после экспорта
изменить наценку, курс или другие исходные параметры расценки, итоговые значения
пересчитаются в Excel.

## Основные формулы

- монтаж всего до переноса: `stops * installation_price_per_stop_rub * (1 + installation_markup)`;
- перенос за 1 остановку:
  - `installation_price_per_stop_rub * (1 + installation_markup) * transfer_share`;
  - или `min(fixed_transfer_per_stop_rub, installation_price_per_stop_rub * (1 + installation_markup))`;
- сумма переноса: `stops * transfer_per_stop_rub`;
- перенесено в лифт: `transfer_total_rub / exchange_rate_rub_per_cny`;
- новая цена лифта: `original_lift_price_cny + transferred_to_lift_cny`;
- новый монтаж: `original_installation_total_rub - transfer_total_rub`.
